C++ 類別與靜態成員函式

理解 static 資料成員與靜態成員函式的共享機制、記憶體特性，以及不透過物件直接呼叫的正確語法。

1. 核心觀念說明

在 C++ 物件導向程式設計中，一般的成員變數與成員函式都隸屬於「個別物件」；但加上 static 關鍵字後，該成員就會變成整個類別（Class）共用：

  • 靜態資料成員（Static Data Member）：所有由同一個類別建立出來的物件，都共享同一份靜態變數記憶體。常用於統計「目前已建立多少個物件」或儲存全體共用的設定值。
  • 靜態成員函式（Static Member Function）：屬於類別本身而非單一物件，因此沒有 this 指標，即使尚未建立任何物件，也能透過 類別名稱::函式名稱() 直接呼叫。
  • 存取限制：靜態成員函式內部只能直接存取其他 static 成員，無法直接存取非靜態（屬於個別物件）的成員變數或函式。

2. 程式碼範例與解說

以下透過視窗類別 CWin 示範如何用靜態變數累計物件數量，並用靜態成員函式找出面積最大的視窗：

C++ 
#include <iostream>
#include <string>
using namespace std;

class CWin {
private:
    string id;
    int width;
    int height;
    static int count; // 宣告靜態資料成員（記錄物件總數）

public:
    CWin(string i = "Default", int w = 10, int h = 10) : id(i), width(w), height(h) {
        count++; // 每建立一個物件，共用計數器加 1
    }

    int area() const {
        return width * height;
    }

    string getId() const {
        return id;
    }

    // 靜態成員函式：回傳目前建立的物件總數
    static int getCount() {
        return count;
    }

    // 靜態成員函式：比較物件陣列中面積最大者
    static CWin largest(CWin arr[], int size) {
        CWin maxWin = arr[0];
        for (int i = 1; i < size; i++) {
            if (arr[i].area() > maxWin.area()) {
                maxWin = arr[i];
            }
        }
        return maxWin;
    }
};

// 必須在類別外部進行靜態資料成員的定義與初始化
int CWin::count = 0;

int main() {
    // 尚未建立任何物件前，即可直接透過類別名稱呼叫靜態函式
    cout << "初始視窗數量: " << CWin::getCount() << endl;

    CWin winArr[3] = {
        CWin("A", 50, 40),
        CWin("B", 80, 60),
        CWin("C", 30, 90)
    };

    cout << "建立後視窗數量: " << CWin::getCount() << endl;

    // 呼叫靜態成員函式找出最大視窗
    CWin best = CWin::largest(winArr, 3);
    cout << "面積最大的視窗為: " << best.getId()
         << " (面積 = " << best.area() << ")" << endl;

    return 0;
}
  • 類別外初始化：int CWin::count = 0; 負責為靜態成員分配實際記憶體空間，宣告與定義必須分開。
  • 呼叫方式：CWin::getCount() 與 CWin::largest(winArr, 3) 皆使用範圍解析運算子 :: 直接從類別呼叫，語意最清楚。

3. 常見錯誤與注意事項

⚠️ 除錯與語法提醒
  • 忘記在類別外定義 static 變數：只在 class 內寫 static int count; 而未在外部寫 int CWin::count = 0;，編譯時會出現 undefined reference to CWin::count 連結錯誤。
  • 在 static 函式中直接存取非靜態成員：例如在 getCount() 中直接寫 return width; 會編譯失敗，因為靜態函式不知道你要讀取哪一個物件的 width。
  • 傳入陣列時發生越界（Out-of-Bounds）：呼叫 CWin::largest(winArr, 3) 時，第二個參數必須傳入陣列的實際元素個數（3），若誤傳超過陣列長度的數字會讀取到未定義的記憶體。

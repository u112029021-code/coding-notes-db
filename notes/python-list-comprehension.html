Python 串列生成式與常用容器操作

掌握 list、set 與 dict 的核心差異，並運用簡潔的生成式（Comprehension）語法高效率完成資料篩選與轉換。

1. 核心觀念說明

在 Python 處理資料集合時，選對內建容器並搭配生成式語法，能大幅減少冗長的 for 迴圈與暫存變數：

  • 三大常用容器特性：list（串列）有序且允許重複元素；set（集合）無序且自動去除重複值，查詢速度為 O(1)；dict（字典）以「鍵值對（Key-Value）」儲存資料，適合快速對應查詢。
  • 串列生成式（List Comprehension）：基本語法為 [運算式 for 變數 in 可迭代物件 if 篩選條件]，可將「走訪、過濾、轉換」濃縮為單行且具備高度可讀性的程式碼。
  • 集合與字典生成式：將外層中括號 [] 改為大括號 {}，即可直接生成去重複的 set 或鍵值對 dict。

2. 程式碼範例與解說

以下示範如何對一組學生成績資料進行及格篩選、加分轉換、去除重複標籤以及建立成績查詢字典：

Python 
# 原始資料：(學生姓名, 原始分數, 修課組別)
records = [
    ("Alice", 85, "AI"),
    ("Bob", 54, "Web"),
    ("Charlie", 92, "AI"),
    ("David", 58, "DB"),
    ("Eva", 76, "Web")
]

# 1. 串列生成式：篩選及格（>= 60 分）的學生姓名
passed_students = [name for name, score, _ in records if score >= 60]
print("及格名單:", passed_students)

# 2. 串列生成式（含三元運算子）：未滿 60 分者補考調整為 60 分，其餘加 5 分（上限 100）
adjusted_scores = [
    min(score + 5, 100) if score >= 60 else 60
    for _, score, _ in records
]
print("調整後分數:", adjusted_scores)

# 3. 集合生成式（Set Comprehension）：取得不重複的修課組別
unique_tracks = {track for _, _, track in records}
print("所有組別:", unique_tracks)

# 4. 字典生成式（Dict Comprehension）：建立「姓名 -> 原始分數」對照表
score_map = {name: score for name, score, _ in records}
print("Charlie 的分數:", score_map["Charlie"])
  • 序列解包（Unpacking）：在 for name, score, _ in records 中，使用底線 _ 代表該迴圈暫時不需要用到的欄位，讓語意更清晰。
  • 條件位置差異：單純「過濾元素」時，if 寫在 for 的後方；若要根據條件「決定轉換後的值（if ... else ...）」，條件式則必須寫在 for 的前方。

3. 常見錯誤與注意事項

⚠️ 除錯與語法提醒
  • 過度巢狀導致可讀性下降：當生成式包含兩層以上的 for 迴圈與多重 if 判斷時，應改回傳統縮排的 for 迴圈，避免寫出難以維護的「一行天書」。
  • 誤用小括號 () 產生生成器：寫成 (x * 2 for x in nums) 建立的是「生成器（Generator Expression）」而非 tuple，只能逐一迭代一次，無法用索引 [0] 存取。
  • 字典鍵值（Key）重複覆蓋：使用字典生成式時，若原始資料出現相同的 Key，後出現的資料會直接覆蓋先前的值，需確認鍵值具備唯一性。

JavaScript DOM 操作與事件監聽基礎

透過 querySelector 與 addEventListener 綁定使用者互動事件，安全地動態更新網頁文字與 CSS 樣式狀態。

1. 核心觀念說明

瀏覽器載入 HTML 後，會將整個網頁文件轉換成樹狀結構的物件模型，稱為 DOM（Document Object Model）。JavaScript 透過操作 DOM 節點來讓靜態網頁具備互動能力：

  • 選取元素：使用 document.querySelector("CSS選擇器") 取得第一個符合條件的 DOM 元素；若需選取多個元素則使用 document.querySelectorAll()。
  • 事件監聽（Event Listener）：透過 element.addEventListener("事件名稱", 回呼函式) 監聽點擊（click）、輸入（input）或表單送出（submit），將結構（HTML）與行為（JS）分離。
  • 動態修改內容與樣式：優先使用 textContent 更新純文字，並透過 element.classList.toggle("class名稱") 切換預先定義好的 CSS 樣式，而非直接寫死行內樣式（inline style）。

2. 程式碼範例與解說

以下示範一個「學習進度打卡按鈕」，點擊時會切換完成狀態樣式並即時更新計數器：

HTML / JavaScript 
<!-- HTML 結構 -->
<div class="task-box">
  <p id="status-text">目前狀態：尚未完成今日練習</p>
  <p>累計打卡次數：<strong id="count-display">0</strong></p>
  <button type="button" id="check-in-btn">完成今日學習打卡</button>
</div>

<script>
  // 確保 HTML DOM 載入完成後再選取元素
  document.addEventListener("DOMContentLoaded", () => {
    const statusText = document.querySelector("#status-text");
    const countDisplay = document.querySelector("#count-display");
    const checkInBtn = document.querySelector("#check-in-btn");

    let count = 0;

    checkInBtn.addEventListener("click", () => {
      count++;
      // 切換 CSS class 控制外觀變化
      const isCompleted = checkInBtn.classList.toggle("is-done");

      // 使用 textContent 安全更新畫面文字
      countDisplay.textContent = count;
      statusText.textContent = isCompleted
        ? "目前狀態：已完成今日練習！"
        : "目前狀態：進行下一輪複習中";
    });
  });
</script>
  • DOMContentLoaded 事件：確保瀏覽器已經解析完所有 HTML 標籤後才執行 JavaScript，避免發生「找不到元素」的錯誤。
  • classList.toggle() 回傳值：切換後若該元素包含該 class 會回傳 true，移除則回傳 false，可直接用來判斷目前狀態。

3. 常見錯誤與注意事項

⚠️ 除錯與語法提醒
  • Cannot read properties of null 錯誤：通常是因為 <script> 寫在 <head> 裡，導致程式執行時按鈕還沒被載入。請將 <script> 放在 </body> 前，或包在 DOMContentLoaded 內。
  • 註冊監聽器時不小心加上括號 ()：寫成 btn.addEventListener("click", handleClick()) 會在網頁載入當下就立刻執行函式，而非等到點擊時才觸發；正確寫法應傳入函式名稱 handleClick（不加括號）。
  • 避免濫用 innerHTML 寫入使用者輸入：若將未過濾的使用者輸入直接塞入 innerHTML，容易引發 XSS（跨站腳本攻擊）；單純顯示文字請一律使用 textContent。

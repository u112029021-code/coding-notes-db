二分搜尋法（Binary Search）原理與實作

理解 O(log n) 時間複雜度優勢，掌握在已排序陣列中利用左右雙指標縮小搜尋範圍的實作與邊界條件。

1. 核心觀念說明

二分搜尋法（Binary Search）是一種建立在「分治法（Divide and Conquer）」概念上的高效搜尋演算法，每一次比較都能排除掉一半的不可能選項：

  • 必要前提條件：目標資料集合必須是「已排序（Sorted）」且支援隨機存取（如陣列 Array 或 Python List）。
  • 搜尋步驟：設定左邊界 left 與右邊界 right，每次取出中間位置 mid 的元素與目標值 target 比較。若相等則回傳索引；若中間值較小，代表目標只可能在右半部，將 left 移至 mid + 1；反之則將 right 移至 mid - 1。
  • 複雜度分析：時間複雜度為 O(log n)（例如在 100 萬筆資料中最多只需比較 20 次），遠快於線性搜尋的 O(n)；使用迴圈實作時的空間複雜度為 O(1)。

2. 程式碼範例與解說

以下使用迭代（Iterative）雙指標寫法，在遞增排序的整數陣列中尋找目標值 target 的索引位置：

Python 
def binary_search(nums: list[int], target: int) -> int:
    # 定義閉區間搜尋範圍 [left, right]
    left = 0
    right = len(nums) - 1

    # 當 left == right 時區間內仍有一個元素，因此條件必須包含等號
    while left <= right:
        # 避免其他語言中 (left + right) 發生整數溢位的標準寫法
        mid = left + (right - left) // 2

        if nums[mid] == target:
            return mid          # 找到目標，回傳索引位置
        elif nums[mid] < target:
            left = mid + 1      # 目標在右半邊，縮小左邊界
        else:
            right = mid - 1     # 目標在左半邊，縮小右邊界

    return -1                   # 搜尋範圍清空仍未找到


if __name__ == "__main__":
    sorted_data = [3, 11, 18, 24, 37, 45, 59, 72, 88]
    print("搜尋 45 的索引:", binary_search(sorted_data, 45))  # 輸出: 5
    print("搜尋 20 的索引:", binary_search(sorted_data, 20))  # 輸出: -1
  • 閉區間不變量（Loop Invariant）：因為初始設定 right = len(nums) - 1，代表搜尋區間兩端都包含在內（[left, right]），所以迴圈條件必須寫 left <= right，且邊界更新時要跳過已經檢查過的 mid（即 mid + 1 與 mid - 1）。
  • 防溢位中點公式：mid = left + (right - left) // 2 在數學上等同於 (left + right) // 2，但在 C++ 或 Java 等固定整數長度的語言中，能防止 left + right 超出 INT_MAX。

3. 常見錯誤與注意事項

⚠️ 除錯與語法提醒
  • 對未排序的陣列直接使用二分搜尋：如果資料沒有先排序，二分搜尋會直接丟棄包含正確答案的那一半區間，回傳錯誤結果（若要先排序再搜尋，整體時間複雜度會變成 O(n log n)）。
  • 邊界更新未加 1 或減 1 導致無窮迴圈：若誤寫成 left = mid 或 right = mid，當搜尋範圍縮小到只剩 2 個元素且目標不存在時，mid 會卡在原地導致 while 迴圈永遠無法結束。
  • 迴圈條件漏掉等號 =：在閉區間寫法中若寫成 while left < right:，當目標剛好位於最後剩下的那個元素時，迴圈會提前結束並誤判為找不到（-1）。
